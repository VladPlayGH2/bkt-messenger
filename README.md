# БКТ Messenger 2.0

Полноценная серверная версия на Node.js:
- регистрация и вход;
- пароли хранятся в виде bcrypt-хеша;
- JWT-авторизация;
- SQLite база пользователей и сообщений;
- поиск пользователей;
- личные чаты;
- сообщения сохраняются в базе;
- WebSocket для доставки новых сообщений в реальном времени.

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

## На VPS

Загрузите проект, выполните `npm install`, затем `npm start`.
Для постоянной работы используйте PM2/systemd, а перед приложением — HTTPS/Nginx.

Перед публикацией обязательно задайте переменную окружения `JWT_SECRET` длинным случайным значением.
