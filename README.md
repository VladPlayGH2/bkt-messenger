# БКТ Messenger — чаты и поиск

Логика списка пользователей изменена:
- после входа не показываются все зарегистрированные пользователи;
- показываются только собеседники, с которыми уже есть сообщения;
- нового друга можно найти через поиск по `@username`;
- после открытия/начала переписки он появляется в «Мои чаты»;
- поиск можно очистить, чтобы вернуться к своим чатам;
- список чатов хранится на сервере через таблицу сообщений.

Запуск:
```bash
npm install
npm start
```


## Звонки

Добавлены WebRTC аудио- и видеозвонки через WebSocket-сигнализацию.
Для работы на телефонах сайт должен быть открыт по HTTPS.

Текущая версия использует публичный STUN-сервер Google. Для максимально надёжной связи через разные NAT/мобильные сети в продакшене желательно добавить TURN-сервер.


## Медиа
Добавлены голосовые сообщения и круглые видеосообщения ("кружочки").
Аудио ограничено 2 минутами, видеосообщение — 60 сек. Файлы сохраняются на сервере.
Для iPhone/Android нужен HTTPS и разрешение на микрофон/камеру.


## Группы и подтверждение разработчиков

Добавлены:
- групповые чаты до 100 участников;
- создание группы из интерфейса;
- добавление участников создателем;
- история групповых сообщений;
- отдельный флаг подтвержденного разработчика с синей галочкой;
- серверная выдача статуса verified;
- административное подтверждение через ADMIN_USER_ID.

В Render можно задать `ADMIN_USER_ID` равным ID твоего аккаунта. После этого администратор может подтверждать пользователей через API `/api/admin/verify/:id`.
