# БКТ Messenger — звонки (исправленная версия)

Исправлено:
- WebRTC ICE-кандидаты теперь передают `callId`.
- ICE-кандидаты, пришедшие до SDP, корректно буферизуются и добавляются после установки remote description.
- Завершение звонка передаёт идентификатор сессии.
- Кнопки звонков находятся рядом с ником.

Важно для реальных звонков через интернет:
- Сайт должен работать по HTTPS.
- Нужен доступ к микрофону/камере.
- Для звонков между разными сетями/мобильным интернетом рекомендуется настроить TURN через `TURN_URL`, `TURN_USERNAME`, `TURN_CREDENTIAL`. Один STUN-сервер не гарантирует соединение.

Запуск:
```bash
npm install
npm start
```
