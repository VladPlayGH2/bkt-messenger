# BKT Messenger — PostgreSQL / Render

Мессенджер теперь использует PostgreSQL вместо SQLite.

## Render

1. Создайте **PostgreSQL** в Render.
2. Создайте Web Service для этого проекта.
3. В Environment Variables добавьте:
   - `DATABASE_URL` — Internal Database URL из Render PostgreSQL.
   - `JWT_SECRET` — длинная случайная строка.
   - `VAPID_SUBJECT` — например `mailto:admin@example.com`.
   - `ADMIN_USER_ID` — ID администратора, если нужна выдача верификации.
   - `NODE_ENV=production`.
4. Build Command: `npm install`
5. Start Command: `npm start`

Таблицы PostgreSQL создаются автоматически при запуске. SQLite (`better-sqlite3`) больше не используется.

### Важно про файлы

PostgreSQL сохраняет аккаунты, профили, сообщения, группы, звонки и push-подписки между перезапусками Render. Загруженные аватары и медиа по-прежнему лежат в локальной файловой системе сервиса; на Render для их долговременного хранения нужен persistent disk или объектное хранилище (S3/R2 и т.п.).

## БКТ Сообщество

При первом запуске автоматически создаётся системная группа **«БКТ Сообщество»**. Каждый новый зарегистрированный пользователь автоматически добавляется в неё, а существующие пользователи добавляются при инициализации базы.

Писать в этой группе могут только пользователи `Brozi` и `Vlad`. Для остальных участников группа доступна только для чтения. Ограничение проверяется на сервере, поэтому его нельзя обойти отключением интерфейсной блокировки.

## Регистрация по номеру телефона
Новая регистрация требует номер телефона и одноразовый код подтверждения. После завершения регистрации номер повторно при обычном входе не вводится — вход выполняется по логину и паролю.

Для отправки SMS в production настройте один из вариантов:
- `SMS_WEBHOOK_URL` — POST JSON `{ "to": "...", "code": "...", "message": "..." }`;
- либо `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_FROM`.

В development без SMS-провайдера код выводится в серверный лог и возвращается интерфейсу только для локального тестирования. Два указанных номера телефона освобождены от ввода кода, но всё равно привязываются к аккаунту.

При запуске автоматически удаляются аккаунты с логином только из цифр и аккаунт `жопочка`. Новые и изменяемые логины с цифрами-only или запрещёнными/нецензурными словами отклоняются на сервере.
