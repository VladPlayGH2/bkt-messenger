# БКТ Messenger — звонки и уведомления

Добавлено:
- аудио- и видеозвонки через WebRTC на ПК и телефонах;
- кнопки 📞 и 📹 перенесены в верхнюю панель рядом с ником;
- входящий звонок показывает окно принятия/завершения;
- при входящем звонке отправляется Web Push-уведомление;
- входящий звонок сохраняется как сообщение в чате;
- если получатель был офлайн, звонок сохраняется как ожидающий и подхватывается после открытия мессенджера;
- для WebRTC предусмотрен STUN и возможность добавить TURN через переменные окружения `TURN_URL`, `TURN_USERNAME`, `TURN_CREDENTIAL`.

Для браузерных звонков на телефоне нужен HTTPS (кроме localhost), а пользователь должен разрешить микрофон/камеру. Для стабильных звонков между разными сетями рекомендуется настроить TURN.

Запуск:
```bash
npm install
npm start
```
